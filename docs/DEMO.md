# Three-minute demonstration

1. Open the editing workspace with **Publish an accessible tutorial**. Explain that these are original demo recordings with synthesized narration; no channel data is needed.
2. Open **Creator profiles**. Show Tight and Deliberate. Point to the learned pause target and six take-selection observations, then open one evidence pair.
3. In **Example library**, play a raw phrase and its corresponding final location. Explain that accepted source matches, rather than a manually selected preset, informed the profile.
4. Return to the unseen tutorial. Create the Tight edit, then switch to **Rendered edit**. Compare the Deliberate edit and generic baseline on the same source. The take preference and spacing differ; source order and changed-number/negation instructions stay preserved.
5. In the local app, restore a take, adjust a pause, lock a segment, undo, and render a new revision. Explain that this revision is the one exported.
6. Download the ZIP and show the real MP4, captions, plan, and source hash manifest.
7. Open **Evidence & exports**. State the small-corpus results and limits: this demonstrates mechanical transfer of constructed preferences, not real creator outcomes or retention improvement.

The hosted version supports exploring saved outputs but disables processing controls. Use the local application for a live upload-to-export recording.
